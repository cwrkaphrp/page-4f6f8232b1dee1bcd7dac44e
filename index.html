客户端接入与路由导入说明

红杏出墙输出通用标准订阅，不强制捆绑专有客户端，用户可依据平台选用成熟工具。

平台环境 推荐协议内核类型 接入方式
Windows / macOS Clash / Sing-box / V2Ray 内核 远程 URL 订阅链接导入
Android Clash Meta / v2rayNG 扫描二维码或手动粘贴订阅串
iOS / iPadOS Shadowrocket / Quantumult X URI 自动化配置文件同步
Linux / 软路由 OpenWrt / Core CLI YAML 规则集静态化部署
  1. 拉取配置凭据：登录红杏出墙控制面板，复制分配的 HTTPS 订阅协议链接。请勿将此链接交由未经授权的第三方。
  2. 新增配置源：打开本地客户端，选择“配置/Profile”栏目，点击“从 URL 下载（Download from URL）”，粘贴该链接并保存。
  3. 选择路由模式：为保障访问效率并节省配额，务必将系统运行模式勾选为“规则分流（Rule-based / PAC）”，避免全局占用。
  4. 连通性检查：在节点列表内执行连通延迟测定，剔除超时节点后选定活跃入口，再启动系统代理总开关。

常见问题排查与运行规范 (FAQ)

以下汇编系统日常使用、流量重置、并发判定及链路诊断的操作规则。

红杏出墙如何判定“多台设备同时在线”配额？
系统网关基于活跃的 TCP/UDP 会话并发 IP 进行动态统计。当并发外部来源 IP 数量超出所选套餐上限（如基础版 3 台、旗舰版 5 台）时，新设备发起的握手请求将被系统列队暂挂，直至既有设备会话自然超时释放。
月度流量额度的计算周期与重置时间点为何？
流量重置遵循订单生成日对应的自然月账单周期，而非按日历月首日统一划扣。当期未用完的流量配额会在到达周期截点时自动归零，不转结至下一个周期；超出额度后节点将限制继续解析，直至下个结算点或额外增购生效。
客户端提示“订阅解析失败”或更新报错时如何处理？
请按以下清单依次核对：1. 确认复制的订阅链接未包含多余的前后空格；2. 检查本地网络 DNS 设置，尝试将本地解析服务器设为主流公共 DNS；3. 在客户端中临时关闭全局代理后再尝试拉取更新；4. 如订阅链接被污染，可在红杏出墙面板中点击“重置订阅凭据”。
规则分流与全局代理模式的切换建议是什么？
建议常驻“规则分流”模式。在此模式下，系统能够通过内置域名规则表自动识别目的地属性，仅对需要境外解析的数据请求走代理节点通道，避免国内常规网络请求消耗宝贵的套餐流量。
节点延迟显示异常或大量节点超时如何诊断？
1. 首先比对计算机或手机系统时间是否与标准北京时间同步，偏差超过 60 秒会导致加密握手认证失败；2. 尝试切换不同运营商入口（电信/联通/移动优化组）；3. 重新下载订阅配置文件，同步最新的后端 IP 池映射表。
